# Allerix iOS (Flutter)

Separate Flutter client for iOS development. The existing Android/Kotlin app remains unchanged.

Built-in server from Api.kt: https://flix.alleriafilmotheque.fyi

The iOS starter is developed in this folder. See the workflow in .github/workflows/build-ios.yml for an unsigned CI build. Full quality/audio transcoding, PiP, brightness/volume gestures and playback-progress sync remain follow-up work.
